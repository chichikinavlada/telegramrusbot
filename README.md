# Telegram-бот для анализа русскоязычного учебного текста

Это учебный проект по Python. Бот принимает кусок учебного текста (лекции, конспекта, статьи) и выдает по нему небольшой лингвистический разбор.

## Что делает бот

- считает количество слов и предложений;
- находит самые частотные леммы (без стоп-слов);
- находит в тексте людей, места и организации;
- строит график по самым частотным леммам;
- сохраняет результаты в базу данных и показывает историю и статистику.

## Что использовано в проекте

Из NLP:
- `nltk` для разбиения на слова и предложения и для списка стоп-слов;
- `pymorphy3` для лемматизации;
- `natasha` для поиска именованных сущностей (NER).

Из других тем курса:
- `pandas` для подсчета частотности лемм;
- `sqlite3` для хранения истории анализов;
- `matplotlib` для графика.

Сам бот написан на `aiogram`.

## Как это работает

Пользователь выбирает действие кнопками и присылает текст. Бот делит текст на слова, лемматизирует их и убирает стоп-слова, считает частотность, ищет сущности, сохраняет результат в базу и отправляет отчет вместе с графиком.

## Структура проекта

- `main.py` — запуск проекта;
- `src/app.py` — запуск бота;
- `src/config.py` — настройки (токен и путь к базе);
- `src/bot/handlers.py` — обработчики сообщений и кнопок;
- `src/bot/keyboards.py` — inline-кнопки;
- `src/services/analyzer.py` — разбор текста;
- `src/services/database.py` — работа с базой данных;
- `src/services/charts.py` — построение графика.

## Версия Python

Проект делался на Python 3.10.

## Установка

```
python -m pip install -r requirements.txt
```

## Токен бота

Токен выдает @BotFather в Telegram. Его нужно записать в переменную окружения `BOT_TOKEN`, например в PowerShell:

```
$env:BOT_TOKEN="ваш_токен"
```

В macOS и Linux:

```
export BOT_TOKEN="ваш_токен"
```

## Запуск

Точка входа: `main.py`

```
python main.py
```

## Как пользоваться

В боте все работает через кнопки:
- «Разобрать текст» — отправить текст на анализ (минимум 30 символов);
- «История» — посмотреть последние анализы;
- «Статистика» — посмотреть свою статистику.

## Ограничения

- Лемматизация через pymorphy3 берет первый вариант разбора и не учитывает контекст, поэтому для омонимов и редких слов (например, фамилий) лемма может быть неправильной.
- `natasha` обучена на новостных текстах, поэтому в учебных текстах находит не все сущности, а иногда ошибается.
- Telegram режет сообщения длиннее 4096 символов, поэтому очень длинный текст бот разберет по частям.
- Стоп-слова берутся из `nltk` и дополнены несколькими словами вручную, список можно расширять.
